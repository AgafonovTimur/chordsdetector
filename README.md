# Chords Detector — VST3

Плагин показывает название аккорда, который ты играешь на MIDI-клавиатуре, прямо в окне DAW.
Интерфейс на русском, английском и китайском.

## Что внутри

```
CMakeLists.txt                  настройки сборки
.github/workflows/build.yml     сборка на GitHub
Resources/PTSansBold.ttf        шрифт, вшивается в плагин
Source/ChordEngine.h            распознавание аккордов (таблицы из веб-версии)
Source/Lang.h                   тексты интерфейса на трёх языках
Source/PluginProcessor.h/.cpp   приём MIDI, сохранение настроек
Source/PluginEditor.h/.cpp      окно плагина и панель настроек
```

## Как собрать через GitHub

1. Создай новый репозиторий на GitHub (можно приватный).
2. Загрузи в него всё содержимое этой папки — так, чтобы `CMakeLists.txt` лежал в корне,
   а не внутри вложенной папки. Папку `.github` тоже нужно загрузить: через веб-интерфейс
   GitHub скрытые папки не перетаскиваются, поэтому либо заливай через `git push`,
   либо создай файл вручную: **Add file → Create new file**, имя
   `.github/workflows/build.yml`, и вставь его содержимое.
3. Сборка запустится сама. Открой вкладку **Actions**.
4. Когда задача закончится, скачай архив **ChordsDetector-VST3-Windows**.
5. Внутри архива папка `Chords Detector.vst3`. Скопируй её **целиком** в
   `C:\Program Files\Common Files\VST3\` или в свою папку для плагинов.
6. В DAW сделай пересканирование плагинов.

## Куда класть плагин

На Windows VST3 — это **папка**, а не один файл. Внутри `Chords Detector.vst3`
лежит `Contents\x86_64-win\Chords Detector.vst3`. Переносить нужно всю внешнюю папку
целиком, вместе с содержимым. Если вытащить из неё только внутренний файл, DAW плагин
не увидит.

## Как подключить в DAW

Плагин работает как инструмент (VSTi), который не издаёт звука.

- **FL Studio** — добавь его в Channel Rack как инструмент.
- **Cubase** — создай Instrument Track и выбери «Chords Detector».
- **Studio One** — перетащи его из браузера инструментов в аранжировку.

Чтобы одновременно слышать звук, поставь Chords Detector первым и направь его
MIDI-выход на нужный инструмент, включив в настройках «Пропускать MIDI дальше».
Обратная схема (роутинг с инструмента на Chords Detector) работать не будет:
обычный сэмплер или синтезатор MIDI наружу не отдаёт, отдавать нечего.

Второй способ для FL Studio — назначить обоим каналам один и тот же входной
MIDI-порт. Тогда оба получают ноты прямо с клавиатуры, и роутинг не нужен.

## Управление

Клавиатурных сокращений в плагине нет намеренно: DAW перехватывает нажатия клавиш
под свои команды (пробел — воспроизведение и так далее), и работали бы они через раз.
Всё управление вынесено в панель настроек.

| Действие | Что делает |
|---|---|
| Кнопка «Настройки» в правом верхнем углу | Открыть или закрыть панель настроек |
| Колесо мыши вверх | Открыть панель настроек |
| Колесо мыши вниз | Закрыть панель настроек |
| Нажатие на колесо мыши | Открыть или закрыть панель настроек |
| Правый нижний угол окна | Изменение размера окна плагина |

Кнопка «Настройки» видна первые 5 секунд после открытия окна, потом становится
невидимой и появляется снова при наведении мыши на правый верхний угол.

## Настройки

Все настройки сохраняются вместе с проектом DAW. Размер окна и то, была ли
открыта панель настроек, — тоже.

### Язык
Русский, английский, китайский. Кнопка сброса настроек язык не трогает.

### Общее
| Настройка | Значения | По умолчанию |
|---|---|---|
| Пропускать MIDI дальше (MIDI Thru) | вкл / выкл | вкл |
| Окно захвата аккорда | 10–500 мс | 50 мс |

**Окно захвата** — сколько времени плагин ждёт остальные ноты аккорда. Ноты копятся,
пока пауза между нажатиями меньше этого значения. Если не успеваешь брать аккорд
достаточно резко и часть нот теряется — увеличь до 150–200 мс. Обратная сторона:
смена аккордов будет отображаться с такой же задержкой.

### Строка аккорда
| Настройка | Значения | По умолчанию |
|---|---|---|
| Подгонять аккорд под ширину окна | вкл / выкл | вкл |
| Размер аккорда | 10–400 % | 100 % |

При включённой подгонке размер шрифта подбирается автоматически под ширину окна,
а ползунок работает как множитель поверх этого.

### Цвета
Цвет фона и цвет текста. Нажатие на кнопку открывает палитру, цвет меняется сразу.
Сама кнопка закрашена в текущий цвет.

### Бемоль вместо диеза
Пять отдельных галок: `C#/Db`, `D#/Eb`, `F#/Gb`, `G#/Ab`, `A#/Bb`.
По умолчанию везде выбран бемоль.

### Тоника и лад
Тоника — одна из 12 нот, лад — один из 9: мажор, натуральный минор, гармонический
минор, мелодический минор, дорийский, фригийский, лидийский, миксолидийский, локрийский.
Оба выбора необязательны, повторное нажатие снимает выбор.

Тоника и лад влияют на две вещи: включают показ ступени лада и помогают выбрать
правильное название, когда один набор нот читается несколькими способами
(например `C Eb G Bb` — это и `Cm7`, и `Eb6`).

### Номер обращения
| Настройка | Значения | По умолчанию |
|---|---|---|
| Показывать номер обращения | вкл / выкл | выкл |
| Размер | 10–400 % | 120 % |
| Положение по горизонтали | 0–100 % | 70 % |
| Положение по вертикали | 0–100 % | 80 % |

Положение задаётся в процентах от размера окна, а не в пикселях, чтобы строка
не уезжала за край при изменении размера окна.

### Ступень лада
| Настройка | Значения | По умолчанию |
|---|---|---|
| Показывать ступень лада | вкл / выкл | выкл |
| Размер | 10–400 % | 120 % |
| Положение по горизонтали | 0–100 % | 30 % |
| Положение по вертикали | 0–100 % | 80 % |

Показывается только если выбраны тоника и лад.

### Полиаккорд
| Настройка | Значения | По умолчанию |
|---|---|---|
| Показывать полиаккорд | вкл / выкл | выкл |
| Положение по горизонтали | 0–100 % | 50 % |
| Положение по вертикали | 0–100 % | 92 % |

Появляется только когда обычный аккорд не определился. Строка вида `Ab / C7(no5)` —
трезвучие поверх басовой ноты с септимой. Отдельного размера у этой строки нет,
она масштабируется вместе с основной.

### По умолчанию
Кнопка в самом низу панели. Возвращает все настройки к начальным значениям,
кроме языка. Новые значения по умолчанию из обновлённой версии применяются только
к заново вставленному плагину — в сохранённых проектах остаются прежние, для них
и нужна эта кнопка.
