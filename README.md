# Chords Detector — VST3

Плагин показывает название аккорда, который ты играешь на MIDI-клавиатуре, прямо в окне DAW.
Интерфейс на русском, английском и китайском.

## Что внутри

```
CMakeLists.txt                  настройки сборки
.github/workflows/build.yml     сборка на GitHub
Resources/PTSansBold.ttf        шрифт, вшивается в плагин
Source/ChordEngine.h            распознавание аккордов (таблицы из веб-версии)
Source/Lang.h                   тексты интерфейса на трёх языках
Source/PluginProcessor.h/.cpp   приём MIDI, сохранение настроек
Source/PluginEditor.h/.cpp      окно плагина и панель настроек
```

## Как собрать через GitHub

1. Создай новый репозиторий на GitHub (можно приватный).
2. Загрузи в него всё содержимое этой папки — так, чтобы `CMakeLists.txt` лежал в корне,
   а не внутри вложенной папки. Папку `.github` тоже нужно загрузить: через веб-интерфейс
   GitHub скрытые папки не перетаскиваются, поэтому либо заливай через `git push`,
   либо создай файл вручную: **Add file → Create new file**, имя
   `.github/workflows/build.yml`, и вставь его содержимое.
3. Сборка запустится сама. Открой вкладку **Actions**.
4. Когда задача закончится, скачай архив **ChordsDetector-VST3-Windows**.
5. Внутри архива папка `Chords Detector.vst3`. Скопируй её **целиком** в
   `C:\Program Files\Common Files\VST3\` или в свою папку для плагинов.
6. В DAW сделай пересканирование плагинов.

## Куда класть плагин

На Windows VST3 — это **папка**, а не один файл. Внутри `Chords Detector.vst3`
лежит `Contents\x86_64-win\Chords Detector.vst3`. Переносить нужно всю внешнюю папку
целиком, вместе с содержимым. Если вытащить из неё только внутренний файл, DAW плагин
не увидит.

## Как пользоваться

Плагин работает как инструмент (VSTi), который не издаёт звука.

- **FL Studio** — добавь его в Channel Rack как инструмент.
- **Cubase** — создай Instrument Track и выбери «Chords Detector».
- **Studio One** — перетащи его из браузера инструментов в аранжировку.

Панель настроек открывается кнопкой в правом верхнем углу, колесом мыши вверх
или нажатием на колесо. Внизу панели есть кнопка сброса на начальные настройки.

Окно плагина тянется за правый нижний угол. Размер окна и все настройки
сохраняются вместе с проектом DAW.
